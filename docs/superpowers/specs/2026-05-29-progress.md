## Phase 1 任务分解（待实施）

### P1-T1：JWT 认证模块
- 新增 `src/auth/jwt.py`：token 生成/验证（PyJWT）
- 新增 `src/auth/dependencies.py`：`get_current_user` FastAPI 依赖
- 密码哈希（passlib[bcrypt]）
- API：`POST /api/auth/register`、`POST /api/auth/login`、`POST /api/auth/refresh`

### P1-T2：多租户数据改造
- 所有 SQLModel 表加 `tenant_id` 字段
- `TenantContext` 中间件：从 JWT 提取 tenant_id，注入 contextvars
- Qdrant 检索加 tenant_id payload filter
- Redis key 加 tenant_id 前缀

### P1-T3：Alembic 数据库迁移
- 初始化 alembic（`alembic init`）
- 初始迁移脚本（创建 auth 相关表 + 现有表加 tenant_id）
- entrypoint 自动运行 `alembic upgrade head`

### P1-T4：Docker Compose
- postgres + redis + qdrant + app 四个服务
- `.env` 环境变量管理
- healthcheck 配置
- 一键 `docker compose up` 启动

### P1-T5：测试验证
- auth API 测试（注册/登录/token 刷新）
- 多租户隔离测试（不同 tenant 数据互不可见）
- 现有测试兼容性验证

## 技术选型（已确定）

| 用途 | 选型 |
|------|------|
| JWT | PyJWT |
| 密码哈希 | passlib[bcrypt] |
| OAuth2 | FastAPI 内置 |
| 数据库迁移 | Alembic |
| 消息队列 | Celery + RabbitMQ（Phase 2） |
| 限流 | Redis Lua（Phase 3） |
| API 网关 | Traefik v3（Phase 3） |
| 监控 | Prometheus + Grafana（Phase 6） |
| 支付 | wechatpayv3（Phase 7） |
| CI/CD | GitHub Actions + ruff + mypy（Phase 8） |
