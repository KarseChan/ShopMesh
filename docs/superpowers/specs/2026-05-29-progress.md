## 架构决策（2026-05-29）

**方案 C：先不拆，后面再分。** Phase 1-3 用 Python 全栈推进，Phase 3 后引入 Java Spring Boot 迁移 CRUD/鉴权。

调整后的路线图：
| 阶段 | 内容 | 语言 |
|------|------|------|
| Phase 1 ✅ | 认证鉴权 + 多租户隔离 | Python |
| Phase 2 ✅ | 消息队列 + 异步任务（Celery + RabbitMQ） | Python |
| Phase 3 ✅ | 分布式限流 + API 网关（Redis Lua + Traefik） | Python |
| Phase 3.5（新增） | Java 后端引入 — CRUD/鉴权迁移 | Java + Python |
| Phase 4 | Agent 生产化 — Guardrails + 成本追踪 | Python |
| Phase 5 | 安全体系 — RBAC + Prompt 安全 + 审计 | Java + Python |
| Phase 6 | 评测体系 + 可观测性 | Python |
| Phase 7 | 支付集成 + 商家后台 API | Java |
| Phase 8 | 容器化部署 + CI/CD | Java + Python |

Java 侧技术栈：Spring Boot 3.x / Spring Data JPA / Spring Security + JWT / Flyway / WebClient
