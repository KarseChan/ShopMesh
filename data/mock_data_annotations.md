## 测试用例 1：跨平台同款比价（3 组）

### 组 A：雅诗兰黛小棕瓶精华
| 平台 | 商品 ID | 价格 | 促销 | 到手价 |
|------|---------|------|------|--------|
| 京东 | prod_001 | ¥599 | 满299减50 | ¥549 |
| 淘宝 | prod_002 | ¥569 | 满100减20 | ¥549 |
| 拼多多 | prod_003 | ¥549 | 无 | ¥549 |

**测试点**：三个平台到手价相同但原价不同，验证 Agent 能否正确计算到手价并给出综合建议（考虑配送时效、平台口碑等其他维度）。

### 组 B：Apple iPhone 15 128GB
| 平台 | 商品 ID | 价格 | 促销 | 到手价 |
|------|---------|------|------|--------|
| 京东 | prod_008 | ¥5999 | 满299减50 | ¥5949 |
| 淘宝 | prod_009 | ¥5799 | 满100减20 | ¥5779 |
| 拼多多 | prod_010 | ¥5599 | 无 | ¥5599 |

**测试点**：拼多多最便宜但无促销，淘宝有促销但仍比拼多多贵，验证多目标排序是否能综合价格+平台信任度。

### 组 C：维达抽纸
| 平台 | 商品 ID | 价格 | 促销 | 备注 |
|------|---------|------|------|------|
| 京东 | prod_020 | ¥49 | 买3件打7折 | 单件原价，3件到手¥102.9 |
| 拼多多 | prod_021 | ¥39.9 | 买2件打85折 | 单件原价，2件到手¥67.83 |

**测试点**：不同平台的不同阶梯折扣策略，验证 Agent 能否对比"单买"和"凑单"的最优方案。

## 测试用例 3：数量追问触发器（2 个）

| 商品 | 商品 ID | 价格 | 促销规则 | 预期 Agent 行为 |
|------|---------|------|----------|----------------|
| 古茗芋泥波波奶茶 | prod_005 | ¥15 | 买3件打7折 | "目前买3件有7折，3件到手¥31.5，单件约¥10.5，要多囤几件吗？" |
| 维达抽纸 | prod_020 | ¥49 | 买3件打7折 | "买3件打7折，3件到手¥102.9，非常划算，要囤货吗？" |

## 测试用例 4：运费陷阱触发器（2 个）

| 商品 | 商品 ID | 商品价格 | 运费 | 实际到手 | 陷阱特征 |
|------|---------|----------|------|----------|----------|
| 索尼 WH-1000XM5 | prod_012 | ¥5 | ¥50 | ¥55 | 正常价¥1999，标价¥5极度异常 |
| 某杂牌精华液 | prod_027 | ¥9.9 | ¥35 | ¥44.9 | 低价商品高运费 |

**测试点**：
- prod_012：验证价格异常检测（历史价¥1999 vs 当前¥5，偏差 > 95%），应触发安全拦截
- prod_027：验证运费陷阱检测（单价¥9.9 + 运费¥35），应通过 HITL 弹出风险提示

## 面试 Demo 推荐流程

### Demo 1：基础工具调用（30 秒）
```
用户："帮我推荐一款护肤品"
→ Agent 推荐雅诗兰黛小棕瓶
→ 展示划线价 ¥599 → 到手价 ¥549（满299减50）
→ 证明：工具调用链路连通
```

### Demo 2：比价 + 多目标排序（30 秒）
```
用户："iPhone 15 哪个平台最便宜？"
→ Agent 展示三平台比价表
→ 拼多多 ¥5599 最低价，但京东有满减 ¥5949
→ 证明：多平台比价 + 多目标排序
```

### Demo 3：主动澄清（30 秒）
```
用户："帮我推荐一款纸巾"
→ Agent："维达抽纸 ¥49，目前买3件有7折优惠，
         3件到手¥102.9，非常划算。要多囤几件吗？"
→ 证明：澄清引擎主动性
```

### Demo 4：安全拦截（30 秒）
```
用户："帮我找最便宜的降噪耳机"
→ Agent："检测到价格异常——索尼 WH-1000XM5 标价 ¥5
         （历史价格 ¥1999，偏差 > 95%）。
         已排除该商品，推荐正常价格的同品类商品。"
→ 证明：安全边界检测
```
